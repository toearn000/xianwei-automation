# 仙位挑战执行规范

目标：每日把「剩余奖励次数」从 5/5 打到 0/5（共 5 场竞技场挑战）。
本文档是引擎（`src/zmws.py`）在「仙位挑战」玩法上的协议层定义：选卡策略、
坐标标定表、状态处理规则、刷新分支与异常约定。坐标与阈值如需变更，
必须与代码常量同步修改。

## 1. 选卡策略（配置驱动，双模式）

对手弹窗固定 4 张卡，奖励从左往右递增（积分 20/40/60/100，最右最高）。
策略存于 `config.json` 的 `xianwei_strategy` 字段，可用 `zmws.py mode [high|low]`
查看/切换：

| 策略 | 决策规则 | 适用 |
|---|---|---|
| `high_power` | 只挑战第 4 卡（奖励最高）；第 4 卡无碾压章 → 直接走刷新分支，**绝不打左侧低奖励卡** | 高战力账号 |
| `low_power`（默认） | 挑战有碾压章的最右卡（尽可能靠右）；全无碾压章 → 走刷新分支 | 低战力账号 |

「碾压章」是游戏自身按战力对比打的红标，脚本检测其存在性即可，不做 OCR
读战力数字。`state`/`scan` 判定为 `opponent_list` 时，返回的
`detail.target`（1~4；0 = 走刷新分支）已按当前策略算好，执行层直接使用，
不重复推算。

## 3. 执行协议

### 3.1 前置条件（由调用方一次性完成）

1. 进入竞技玩法 → 仙位页签 → 打开对手弹窗。
2. 读底部状态栏：剩余次数 N（0/5 则直接关闭弹窗结束）、我的战力 M；
   「开启碾压模式」未勾选则勾上。
3. 调用 `zmws.py xianwei <N> <工作目录>` 进入全自动循环。

### 3.2 循环内状态处理规则

| 状态 | 动作 | 时序 |
|---|---|---|
| `opponent_list`，target ≥ 1 | 点击对应卡挑战 | 点击后等待 4s |
| `opponent_list`，target = 0 | 点刷新（计数 +1，超限则停机 `refresh_exhausted`） | 等待 2s |
| `confirm` 且上一步是刷新 | 点「确定」（事件记 `refresh_confirm`） | 等待 2s |
| `confirm` 但上一步非刷新 | **停机** `unexpected_confirm`，存图交回人工 | — |
| `victory` | 胜场 +1（本地计数），点「确定」 | 等待 3s |
| `rankup` | 点「确定」（事件记 `rankup`） | 等待 3s |
| `drop` | 点「继续游戏」（事件记 `drop`） | 等待 3s |
| `unknown` | 重试 ≤ 2 次（间隔 3s）；仍不识別则停机 `unknown_state`，存图交回人工 | — |

收尾：胜场达标后补拍一张终态图，输出
`SUMMARY {"ok":..., "reason":..., "wins":..., "refreshes":..., "events":..., "duration_s":..., "last_shot":...}`。
调用方核对终态图底部状态栏 0/5 作为完成判据，然后点 X 关闭弹窗。

### 3.3 计数与读数纪律

- 剩余次数**开局读一次、循环内本地计数**（每场 victory 减 1），中途不为
  读数额外看图。
- 底部状态栏数字在胜利结算画面期间是旧值，任何读数以回到对手弹窗后的
  截图为准。

## 4. 刷新分支规则

- 当天刷新计数从 0 开始，上限默认 15 次（`xianwei_max_refresh` 可配，
  全自动模式同样生效）。
- 免费档刷新直接生效；进入付费档后每次刷新先弹「本次刷新将消耗 xxx」
  确认框（`confirm` 状态自动处理）。
- **成本递增极陡**：实测第 1 次付费 1000 游戏币 → 第 15 次已显示 50000。
  低战力账号用 `high_power` 策略时必须下调刷新上限，避免烧货币。
- 达上限仍无 target → 停机 `refresh_exhausted`，剩余次数留待次日。
- 画面提示货币不足 → 停止本模块并在总结中说明。

## 5. 异常约定（升级规则）

以下任一情况发生时，运行总结第一行必须是醒目警告
（`⚠️ 仙位挑战未完成：<原因>`），挂接推送时警告必须进入推送正文：

- 刷新次数用尽仍无法碾压
- 货币不足导致无法刷新
- 出现失败场次（碾压局理论上必胜，失败说明判定出错）
- 每周日 23:00 后不可挑战时段
- 登录失效、画面无法识别等导致流程中断

## 6. 已知边界

- 胜利后可能连弹「段位提升」遮挡对手列表，此时对卡片位置的点击会被吞掉，
  必须先关弹窗再点挑战（状态机顺序处理天然覆盖）。
- 每周越靠后高战力对手越多，不能碾压属正常，走刷新分支。
- 每周一 0 点重置；每周日 23:00 后不可挑战。
- 失败结算画面**刻意不标定**：判 `unknown` 停机交回人工是设计行为，
  宁可漏报不可误操作。
